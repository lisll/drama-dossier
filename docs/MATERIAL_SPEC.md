# 素材与报审包规格

## v1 输入扫描规则

1. 用户选择一个素材根目录。
2. 素材根目录下每个非隐藏子目录视为一部剧。
3. 剧目目录中的视频和元数据文件会被读取；一层子目录也会被扫描。
4. 视频扩展名：`mp4`、`mov`、`mkv`、`flv`、`ts`、`m4v`、`webm`。
5. 图片扩展名：`jpg`、`jpeg`、`png`、`webp`。
6. 文本扩展名：`txt`、`md`。

集号解析优先级：

1. `第12集`、`第12话`、`第12回`
2. 词边界形式的 `E12` 或 `e03`
3. 文件名主干中的独立数字，如 `show_12`

## v1 检查规则

默认值可在未来版本中开放为设置：

| 项目 | 默认规则 | 级别 |
|---|---:|---|
| 分集数量 | 少于 4 集警告，0 集失败 | warn / fail |
| 单集时长 | 31–480 秒之外警告 | warn |
| 码率 | 超过 8 Mbps 建议规范化 | warn |
| 画幅 | 高大于宽为建议竖屏 | warn |
| 封面 | 缺失失败 | fail |
| 简介 | 缺失失败，少于 30 字警告 | fail / warn |

`ready` 只表示没有失败项；警告仍应由人工确认。

## v1 报审包结构

```text
报审包/
├── 01_剧集信息/
│   ├── 剧名.txt
│   └── 简介.txt
├── 02_封面海报/
│   └── 封面.jpg
├── 03_分集清单/
│   └── 分集清单.csv
├── 04_成本配置表/
│   └── 成本配置表.md
├── 05_权属声明/
│   └── 内容权属声明.txt
├── 06_分集视频/
│   └── 第01集.mp4
└── manifest.json
```

`06_分集视频` 仅在勾选「复制分集视频进报审包」时生成。

## manifest.json

字段：

```json
{
  "schema": "drama-dossier/package@1",
  "dramaName": "示例短剧",
  "generatedAt": "2026-10-13T20:00:00Z",
  "aiGenerated": false,
  "files": [
    {
      "path": "01_剧集信息/剧名.txt",
      "sha256": "..."
    }
  ]
}
```

`manifest.json` 是本地完整性清单，不是官方审核回执，也不能替代任何公章、签名或可信时间戳。

## 权属声明模板

报审包固定包含权属声明模板，要求使用者填写素材来源、授权状态和联系人。模板只是提示使用者履行确认义务，不生成法律效果，也不改变材料的真实性责任。
