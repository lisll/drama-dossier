# 竞品页面分析：Grove-Max vs 剧备 DramaDossier

> 依据 2026-10-14 采集的 Grove-Max 0.4.2 页面截图（13 张）与本项目前端源码（`src/index.html`、`src/main.js`）做的纯页面维度对比。本轮仅做技术分析，不涉及任何改造。

## 一、Grove-Max 页面全景

多页面工作台：5 个一级模块（生成 / 挂载 / 转码 / 工具箱 / 设置）+ 设置中心 6 个子页（账号 / 账单 / 剪映 / AI / 本机环境 / 关于）。

| 模块 | 页面要点 |
|------|---------|
| 登录 / 注册 | 邮箱+密码登录、6 位邮箱验证码注册、忘记密码；底部声明「报审包只生成在本地目录，账号仅用于 AI 积分与账单」 |
| 生成（首页） | 顶部红色状态横幅：运行环境未就绪 → 禁用生成（错误码 `RUNTIME_NOT_INSTALLED`）+「下载运行环境」一键自举（ffmpeg / Chromium / Python / 模型组件）；选目录卡片写明前置条件（1 份故事简介 + 1 张竖版封面 + ≥4 可读分集），强调「先做素材检查，不会直接生成」 |
| 挂载 | 4 步向导：素材（目录与题序）→ 文案（CSV 校验）→ 账号（视频号登录）→ 执行（自动上传）；生成「挂载文案.csv」，AI 只在确认后替换文案；根目录放简介 TXT 和海报，视频放「素材」文件夹，剧名默认取目录名 |
| 转码 | 两种模式卡片：「分集重组」（按场景切点重新分集，保持集数与剧情顺序）、「智能微锁」（每集同步微调 -1~3 帧，每次不同）；直接执行，不是建议 |
| 工具箱 | 卡片式独立工具：改名工具（按「剧名 - 第几集」统一命名，先完整预览再确认修改）、码率修复（读取每个 MP4 码率，只重编码低于 4 Mbps 的文件到安全范围） |
| 设置 - 账号 | 登录邮箱展示、修改密码（改后踢掉其他设备会话） |
| 设置 - AI | 提示词模板（云端拉取模板列表，失败可重试） |
| 设置 - 账单 | 剩余生成次数、积分余额、单价（精工细修 60 积分/次）、近 30 天消耗、积分流水；积分由产品方线下发放 |
| 设置 - 剪映 | 剪映安装目录 + 版本自动检测、剪映草稿目录配置（生成完成后草稿自动装配进剪映） |
| 设置 - 本机环境 | 工作目录（`~/Grove-Workspace`，每次任务按剧名建子文件夹）、本地引擎状态 + 下载运行环境 / 重新检测 |
| 设置 - 关于 | 应用版本（0.4.2）与引擎版本（0.3.5）分离显示、独立检测更新 |

## 二、剧备现状（页面视角）

单页应用：顶栏选根目录 → 左侧剧目列表 → 主区依次堆叠：

1. 检查结果清单 + 分集规格表
2. 生成报审包表单（输出目录 / ffprobe 路径 / 公司 / 投资额 / 演员成本占比 / 联系方式 / 复制分集 / AI 声明）
3. 折叠工具区：转码建议（仅产出命令）、报审包差异对比、平台档案对照、剪映草稿导出/读回
4. 折叠的字幕 / 角标擦除（直接暴露 dilate / feather / ROI / worker 等技术参数）
5. 折叠的检查规则与路径设置

## 三、页面维度差距清单（按重要性排序）

| # | 差距 | 说明 |
|---|------|------|
| 1 | 信息架构 | 竞品是「工作台多模块」，剧备是单页折叠堆叠，功能入口可发现性差 |
| 2 | 运行环境自举 | 竞品全局检测 ffmpeg / Chromium / Python / 模型组件并一键下载安装；剧备要求用户自备 ffprobe 且手填路径，无引导 |
| 3 | 转码只建议不执行 | 竞品直接执行（重组分集 / 微调帧防查重）；剧备只产出 ffmpeg 命令，「智能微锁」类能力完全没有 |
| 4 | 挂载发布流水线 | 4 步向导（素材 → 文案 CSV → 视频号账号登录 → 自动上传）剧备完全没有 |
| 5 | 账号体系 | 登录 / 注册 / 验证码 / 多端会话管理，剧备无 |
| 6 | AI 能力与计费 UI | 云端提示词模板 + AI 换文案 + 积分 / 账单 / 流水；剧备只有「AI 生成声明」勾选框 |
| 7 | 工具箱形态 | 竞品卡片化独立工具（批量改名 + 预览确认、码率修复）；剧备无改名工具、无码率修复 |
| 8 | 剪映集成深度 | 竞品有安装目录 / 版本自动检测 + 生成后自动装配草稿；剧备仅手动导出 / 读回 |
| 9 | 应用 / 引擎分离升级 | 竞品版本独立检测更新；剧备无版本页与更新机制 |
| 10 | 任务工作区 | 竞品固定工作目录、每任务独立文件夹；剧备输出目录是可选项 |
| 11 | 空态与前置条件引导 | 竞品每步写明材料要求；剧备只有初始 placeholder 文案 |
| 12 | 参数暴露度 | 剧备擦除功能直接暴露膨胀 / 羽化 / ROI / worker 参数，对非技术用户不友好；竞品全部收敛为模式卡片 |

## 四、反向差异（剧备有、竞品页面未展示）

- 剧目库批量扫描管理（左侧列表多剧目管理）
- 检查清单 + 分集规格探测表（时长 / 分辨率 / 码率逐集展示）
- 报审包 manifest 差异对比
- 平台材料要求档案对照
- 成本表（投资总额 / 演员成本占比）
- 检查规则阈值自定义
- 字幕 / 角标擦除管线（竞品对应「精工细修」条目，但页面未见参数与校验细节）

## 五、小结

页面层面 Grove-Max 的核心优势是三件事：

1. **产品化包装**：多页工作台、分步向导、状态横幅、空态引导
2. **商业化闭环**：账号体系 + 积分计费 + 云端提示词模板
3. **环境自举**：运行时一键下载安装，应用与引擎分离升级

剧备的功能底子（检查、包生成、差异对比、擦除管线）在竞品页面上反而看不到对应深度，差距主要在「壳」和「运营能力」，不在核心管线。
